# 微信RPA框架更新实施计划

## 一、目标
基于现有C++代码进度，结合四个关键方向（Linux辅助功能API、拟人化策略、Flask接口封装、视觉AI驱动），更新微信RPA框架。

## 二、当前状态分析

### 已完成模块
- ✅ 基础C++框架
- ✅ 窗口管理（WindowManager）
- ✅ 图像处理（ImageProcessor）
- ✅ OCR识别（OCREngine）
- ✅ Python绑定

### 存在问题
- ⚠️ 鼠标控制在某些环境下不稳定
- ⚠️ UI元素检测准确性有待提升
- ✅ 微信反自动化问题已通过ATSPI方案解决

### 微信自动化特殊性
微信4.0+版本加强了反自动化检测机制，传统方法（如SendMessage、DLL注入）易被检测。本项目采用以下策略：

1. **Linux ATSPI辅助功能API方案**：
   - 直接访问UI控件树，绕过界面检测
   - 通过系统级辅助功能API操作界面
   - 难以被应用层检测

2. **拟人化策略**：
   - 模拟人类操作行为
   - 随机化操作间隔和轨迹
   - 降低被行为分析算法识别的风险

3. **多层降级机制**：
   - 优先使用ATSPI引擎
   - 降级到系统命令
   - OCR视觉识别作为补充

### 环境特点
- 操作系统：Linux (Manjaro)
- 微信版本：Linux版微信 (4.0+)
- 现有技术栈：C++ + Python + OpenCV + Tesseract OCR

## 五、实施步骤

```bash

sudo pacman -S at-spi2-core atk-bridge-2.0

# 安装Flask
pip install flask

# 检查权限
xhost +
```

### 第二步：代码更新
```bash
# 更新CMakeLists.txt
git add CMakeLists.txt

# 添加新文件
git add src/atspi_engine.cpp
git add src/humanization_engine.cpp
git add include/atspi_engine.h
git add include/humanization_engine.h

# 提交更改
git commit -m "添加ATSPI和拟人化模块"

# 重新编译
./build.sh
```
